# 1장 핵심 개념 정리

## 프로그래밍 패러다임

| 구분 | 내용 |
|---|---|
| 전통적 프로그래밍 | **규칙**을 사람이 작성 → 데이터를 처리 |
| 머신러닝 | **데이터**를 주면 규칙을 스스로 생성 |

- 머신러닝을 쓰는 게 좋은 경우: 규칙이 길고 복잡하며 유지 보수가 잦을 때 (예: 스팸 필터)
- **데이터 마이닝**: 인간이 인지하지 못한 규칙을 데이터에서 발견

## 학습의 종류

| 종류 | 레이블 | 예 |
|---|---|---|
| 지도 학습 | 있음 | 스팸 필터, 회귀 |
| 비지도 학습 | 없음 | 군집, 차원 축소 (지도학습 전에 라벨이 없을 때 유용) |
| 강화 학습 | 데이터 없음 | 보상으로 정책 학습 |
| 준지도 학습 | 일부만 | 레이블 소량 + 다량의 비레이블 |

## 학습 방식

| 구분 | 내용 |
|---|---|
| 온라인 학습 | 데이터 수집과 학습을 번갈아 수행 (새 데이터에 빠르게 적응) |
| 배치(오프라인) 학습 | 데이터 수집 단계와 학습 단계를 분리 |
| 외부 메모리 학습 | 외부 저장소의 데이터를 이용한 배치 학습 (수집과 학습이 비동기) |
| 사례 기반 학습 | 예측 단계에서도 데이터 필요 (예: k-최근접 이웃) |
| 모델 기반 학습 | 예측 단계에서 데이터 불필요 (파라미터로 예측) |

## 학습률(learning rate)

- **높으면**: 시스템이 데이터에 빠르게 적응하지만, 예전 데이터를 금방 잊음 (관성 저하)
- **낮으면**: 시스템의 관성이 커져 느리게 학습. 새 데이터의 잡음에 둔감

## 파이프라인 주요 단계

1. 데이터 수집 2. 데이터 전처리(이상치/특이치 탐지) 3. 특성 공학(추출·생성·선택·변환) 4. 시각화 5. 모델 훈련 6. 모델 평가 7. 실제 응용/예측
