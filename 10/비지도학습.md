## 비지도 학습의 세 가지 작업

| 작업 | 내용 |
|---|---|
| **군집(clustering)** | 비슷한 샘플을 클러스터로 모음 — 데이터 분석, 고객 분류, 추천 시스템, 검색 엔진, 이미지 분할, 준지도 학습, 차원 축소 |
| **이상치 탐지(outlier detection)** | '정상' 데이터가 어떻게 보이는지 학습하고 비정상 샘플을 감지 (제조 라인 결함, 시계열의 새로운 트렌드) |
| **밀도 추정(density estimation)** | 데이터 생성 확률 과정의 확률 밀도 함수(PDF)를 추정. 밀도가 매우 낮은 영역의 샘플이 이상치일 가능성이 높음 |

## 1. k-평균 (k-means)

- 반복 몇 번으로 데이터셋을 빠르고 효율적으로 클러스터로 묶는 간단한 알고리즘 (로이드-포지 알고리즘)
- 각 클러스터의 **센트로이드(중심)** 를 찾고, 가장 가까운 클러스터에 샘플을 할당

```python
from sklearn.cluster import KMeans

k = 5
kmeans = KMeans(n_clusters=k, random_state=42)
y_pred = kmeans.fit_predict(X)     # 훈련된 샘플의 예측 레이블
kmeans.predict([[0, 0], [12, 3]])  # 새로운 샘플은 가장 가까운 센트로이드의 클러스터
kmeans.cluster_centers_            # 센트로이드 좌표
```

### 알고리즘

1. 센트로이드를 랜덤하게 선정 (또는 데이터셋에서 k개 샘플을 뽑아 위치로)
2. 샘플에 레이블 할당 → 센트로이드 업데이트 → 다시 할당 … 을 **센트로이드에 변화가 없을 때까지** 반복
3. 수렴은 보장됨 (샘플과 가장 가까운 센트로이드 사이의 평균 제곱 거리가 매 단계 줄어들 수만 있음)

### 초기화와 지역 최적점

- 수렴은 보장되지만 **지역 최적점**으로 수렴할 수 있음 → 초기화에 따라 결과가 달라짐
- **k-평균++ 초기화** (기본값)
  1. 데이터셋에서 랜덤하게 하나의 센트로이드 c(1) 선택
  2. D(x⁽ⁱ⁾)² / ΣD(x⁽ʲ⁾)² 확률로 샘플을 새 센트로이드로 선택 (이미 선택한 센트로이드에서 **멀리 떨어진** 샘플이 뽑힐 가능성이 높음)
  3. k개가 선택될 때까지 반복
- `n_init` 으로 랜덤 초기화 반복 횟수 조절

### 성능 지표 — 이너셔(inertia)

- 각 샘플과 가장 가까운 센트로이드 사이의 **제곱 거리 합**
- `score()` 는 이너셔의 음숫값을 반환 (클수록 좋게 만들기 위해)
- 단, **이너셔는 k가 증가하면 계속 작아지므로** k 선택 지표로는 부적합

### 최적의 클러스터 개수 — 실루엣 점수

- 모든 샘플의 **실루엣 계수** 평균
- **실루엣 다이어그램**: 샘플의 실루엣 계수를 클러스터별로 정렬해 그린 그래프 — 각 클러스터의 크기와 계수 분포를 함께 볼 수 있음

### 미니배치 k-평균

- 전체 데이터 대신 **미니배치**로 센트로이드를 조금씩 이동 → `MiniBatchKMeans`
- 이너셔는 조금 높지만 **훨씬 빠름** (k가 커질수록 차이가 큼)

### k-평균의 한계

| 장점 | 단점 |
|---|---|
| 빠르고 확장이 용이 | 최적이 아닌 솔루션을 피하려면 여러 번 실행해야 함 |
| | 클러스터 개수 k를 지정해야 함 |
| | 클러스터의 **크기·밀집도가 다르거나 원형이 아니면** 잘 작동하지 않음 (센트로이드까지 거리만 고려하기 때문) |

- 결정 경계는 **보로노이 다이어그램** 모양
- **하드 군집**: 샘플을 하나의 클러스터에 할당 / **소프트 군집**: 클러스터마다 점수 부여 (`transform()` 은 샘플과 각 센트로이드 사이의 거리 반환)

### 활용

- **이미지 분할**: 색상 분할(같은 색 픽셀 = 같은 세그먼트), 시맨틱 분할(같은 종류 물체), 인스턴스 분할(개별 객체)
- **준지도 학습**: 레이블이 적을 때 → 클러스터링 후 대표 이미지 50개만 레이블링하고 **레이블 전파(label propagation)**. 사이킷런의 `LabelSpreading`, `LabelPropagation`
  - 50개 레이블만으로 74.8% → 90.9%까지 정확도 향상 사례
- **능동 학습(active learning)**: 불확실성 샘플링 — 모델이 가장 불확실하게 예측한 샘플을 전문가에게 보내 레이블을 받음

## 2. DBSCAN

- **DBSCAN(density-based spatial clustering of applications with noise)**: 밀집된 **연속적 지역**을 클러스터로 정의
- 각 샘플에서 거리 **ε(eps)** 내에 샘플이 몇 개 있는지 계산 → 이 지역을 **ε-이웃(ε-neighborhood)**
- (자기 자신을 포함해) ε-이웃 내에 적어도 **min_samples** 개 샘플이 있으면 **핵심 샘플(core instance)**
- 핵심 샘플의 이웃에 있는 모든 샘플은 같은 클러스터 → 핵심 샘플의 이웃의 이웃도 이어져 하나의 클러스터 형성
- 핵심 샘플도 아니고 이웃도 아니면 **이상치**

```python
from sklearn.cluster import DBSCAN

dbscan = DBSCAN(eps=0.2, min_samples=5)
labels = dbscan.fit_predict(X)   # predict() 는 제공하지 않음
dbscan.labels_                   # -1 이면 이상치
dbscan.core_sample_indices_      # 핵심 샘플 인덱스
```

- 클러스터가 밀집되지 않은 지역과 **잘 구분될 때** 좋은 성능
- eps를 키우면 이웃 범위가 넓어져 더 큰 클러스터를 만듦 (작으면 많은 샘플을 이상치로 판단)
- **새로운 샘플을 예측할 수 없음** → 필요한 예측기를 따로 학습 (예: `KNeighborsClassifier` 를 핵심 샘플로 훈련)

> [!note] k-평균 vs DBSCAN
> - k-평균: 클러스터 수 k를 정해야 하고, 원형·비슷한 크기 가정. 빠름
> - DBSCAN: k를 정할 필요 없고 임의 모양 클러스터 + 이상치 탐지 가능. 대신 eps·min_samples에 민감

## 3. 다른 군집 알고리즘

| 알고리즘 | 특징 |
|---|---|
| 병합 군집(agglomerative) | 클러스터 계층을 밑바닥부터 위로 쌓아 구성 |
| BIRCH | 대규모 데이터셋을 위해 고안 |
| 평균-이동(mean-shift) | 각 샘플 중심의 원을 그리고, 원 안 샘플의 평균으로 중심을 이동 → 모든 원이 멈출 때까지 반복 |
| 유사도 전파(affinity propagation) | 샘플끼리 메시지를 교환해 자신을 대표할 **예시(exemplar)** 를 선택 |
| 스펙트럼 군집(spectral) | 유사도 행렬 → 저차원 임베딩 → 그 공간에서 다른 군집 알고리즘 |

## 4. 가우스 혼합 모델 (GMM)

- 샘플이 **파라미터가 알려지지 않은 여러 개의 혼합된 가우스 분포**에서 생성되었다고 가정하는 확률 모델
- 가장 간단한 버전이 `GaussianMixture` 클래스
- 사전에 가우스 분포의 개수 k를 알아야 함
- 생성 과정: 샘플마다 k개 클러스터 중 하나를 확률 φ(j)로 선택 → 선택된 클러스터 j의 가우스 분포 N(μ⁽ʲ⁾, Σ⁽ʲ⁾)에서 위치를 샘플링

```python
from sklearn.mixture import GaussianMixture

gmm = GaussianMixture(n_components=3, n_init=10, random_state=42)
gmm.fit(X)

gmm.predict(X)          # 하드 군집
gmm.predict_proba(X)    # 소프트 군집 (클러스터별 확률)
gmm.score_samples(X)    # 각 위치의 로그 확률 밀도(PDF)
```

### EM 알고리즘

| 단계 | 내용 |
|---|---|
| 기댓값(expectation) | 샘플을 클러스터에 할당 (속할 추정 확률 = **책임(responsibility)** 으로 가중치) |
| 최대화(maximization) | 각 클러스터의 가중치·평균·공분산을 업데이트 |

- GMM은 **생성 모델**이므로 새로운 샘플을 만들 수 있음
- 특성·클러스터가 많거나 샘플이 적으면 EM이 최적해로 수렴하기 어려움 → `covariance_type` 으로 파라미터 수 제한

| `covariance_type` | 의미 |
|---|---|
| `"spherical"` | 모든 클러스터가 원형 (지름은 다를 수 있음) |
| `"diag"` | 타원형 가능하나 축이 좌표축과 나란해야 함 (대각 행렬) |
| `"tied"` | 모든 클러스터가 동일한 모양·크기·방향 (공분산 공유) |

### 이상치 탐지

- 밀도가 낮은 영역의 샘플을 이상치로 판단 (`score_samples()` 활용)
