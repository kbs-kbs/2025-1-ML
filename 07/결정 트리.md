# 결정 트리 (Decision Tree)

> 「기본 개념 → 학습과 시각화 → 예측 → CART → 규제 → 회귀」 순서로 정리

## 1. 기본 개념

- **결정 트리**: 트리 구조를 기반으로 데이터에서 규칙을 학습하는 모델. 분류와 회귀 모두 가능
- 스무고개처럼 **질문에 따라 데이터를 구분**해 나감
  - 첫 번째 기준: **Root node**
  - 중간의 기준: **Intermediate node**
  - 마지막 기준: **Leaf node**
- 복잡한 데이터도 빠르게 동작하고, **다른 알고리즘에 비해 전처리가 거의 필요 없음**
- 단점: 규제 없이 계속 깊어지면 **과대적합**되기 쉬움

### 과대적합 방지 — 가지치기(Pruning)

- 파라미터 규제로 트리의 최대 깊이, 노드 분할의 최소 데이터 수를 제한
- 대표 하이퍼파라미터

| 파라미터 | 의미 |
|---|---|
| `max_depth` | 트리의 최대 깊이 |
| `max_features` | 각 노드에서 분할에 사용할 특성의 최대 수 |
| `max_leaf_nodes` | 리프 노드의 최대 수 |
| `min_samples_split` | 분할되기 위해 노드가 가져야 하는 최소 샘플 수 |
| `min_samples_leaf` | 리프 노드가 되기 위해 가져야 할 최소 샘플 수 |
| `min_weight_fraction_leaf` | `min_samples_leaf` 의 가중치 버전(전체 샘플 수에서의 비율) |

## 2. 불순도 (impurity)

- **불순도**: 개체들의 무질서함을 측정하는 지표. 주로 분류에서 사용
- 결정 트리는 **불순도가 0에 가깝게** 되는 방향으로 데이터를 나눔

### 지니 불순도 (Gini impurity)

$$ G_i = 1 - \sum_{k} p_{i,k}^2 $$

- "정답이 아닌 다른 라벨이 뽑힐 확률"
- 파란 구슬만 있으면 0, 빨간 구슬만 있어도 0, **반반이면 0.5**(불순도 최대)

| 예 | 계산 | 지니 불순도 |
|---|---|---|
| 사과만 100% | 1 − 1² | **0** (완전히 순수) |
| 사과 50% + 바나나 50% | 1 − (0.5² + 0.5²) | **0.5** (완전히 섞임) |
| 사과 2/3 + 바나나 1/3 | 1 − ((2/3)² + (1/3)²) | 약 **0.444** |

### 엔트로피 (entropy)

$$ H_i = -\sum_{k} p_{i,k} \log_2(p_{i,k}) $$

- 불순도를 수치적으로 나타낸 척도. 지니와 같은 의미이지만 계산식에 **로그**가 포함
- 순수하게 분류되면 0, **완벽하게 섞이면(5:5) 1**

| 불순도 | 순수(한 클래스만) | 완전히 섞임(5:5) |
|---|---|---|
| 지니 | 0 | 0.5 |
| 엔트로피 | 0 | 1 |

- `DecisionTreeClassifier` 의 기본값은 **gini** (`criterion="entropy"` 로 변경 가능)
- 지니가 계산이 조금 더 빨라 기본값으로 좋음. 엔트로피는 조금 더 **균형 잡힌 트리**를 만드는 경향

## 3. 학습과 시각화

```python
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier, export_graphviz

iris = load_iris(as_frame=True)
X, y = iris.data, iris.target

tree_clf = DecisionTreeClassifier(max_depth=2, random_state=42)
tree_clf.fit(X, y)

# graphviz로 트리 시각화
export_graphviz(tree_clf, out_file="iris_tree.dot",
                feature_names=iris.feature_names,
                class_names=iris.target_names, rounded=True, filled=True)
```

- 노드의 속성

| 속성 | 의미 |
|---|---|
| `samples` | 해당 노드에 적용된 훈련 샘플 수 |
| `value` | 노드에서 각 클래스에 속한 훈련 샘플 수 |
| `gini` | 지니 불순도 |

## 4. 예측

- 한 샘플이 어느 리프에 도달하는지 따라가면 클래스가 결정됨
- **클래스 확률 추정**: 리프 노드에서 클래스별 샘플 비율을 확률로 사용
- 결정 트리의 결정 경계는 축에 수직인 직선들로 이루어짐(계단 모양)

### 화이트박스 vs 블랙박스

| 구분 | 예 | 특징 |
|---|---|---|
| 화이트박스 | 결정 트리 | 결정 방식을 이해하기 쉬움, 수동으로 따라 해볼 수 있음 |
| 블랙박스 | 랜덤 포레스트, 신경망 | 성능은 뛰어나지만 왜 그런 예측을 했는지 설명하기 어려움 |

- 해석 가능한 ML(interpretable ML)은 사람이 이해할 수 있게 모델의 결정을 설명하는 시스템을 만드는 것이 목표

## 5. CART 훈련 알고리즘

- **CART(Classification And Regression Tree)**: 결정 트리 훈련 알고리즘
- 하나의 특성 k와 임계값 t를 골라 비용 함수를 최소화하는 방식으로 분할
- 분류 비용 함수(지니 불순도 기준)

$$ J(k, t_k) = \frac{m_{\text{left}}}{m} G_{\text{left}} + \frac{m_{\text{right}}}{m} G_{\text{right}} $$

- 훈련 복잡도: **O(n × m log₂(m))** (모든 샘플 × 모든 특성 비교)

## 6. 회귀 트리

```python
from sklearn.tree import DecisionTreeRegressor

tree_reg = DecisionTreeRegressor(max_depth=2, random_state=42)
tree_reg.fit(X, y)
```

- `DecisionTreeRegressor` 사용
- 각 영역의 **예측값은 그 영역에 있는 타깃값의 평균**
- 알고리즘은 예측값과 가능한 한 많은 샘플이 가까이 있도록 영역을 분할 (MSE 최소화)
